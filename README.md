📥 Requisitos e Instalación
Descargar el Instalador 📂

Ve a la carpeta de este repositorio o descarga la versión correspondiente a tu sistema operativo (Windows, Linux o macOS).

Ejecutar el Instalador ⚙️

Haz doble clic en el archivo descargado.

Sigue los pasos del asistente haciendo clic en Siguiente ➡️.

Completar la Instalación 🏁

Selecciona la ruta de instalación deseada y haz clic en Instalar.

Una vez finalizado, marca la casilla Ejecutar PSeInt y haz clic en Finalizar 🎉.

⚙️ Configuración Inicial
Al abrir PSeInt por primera vez, verás una ventana para seleccionar el perfil de configuración:

Opciones de Perfil:

🏫 Perfil Institucional: Si tu universidad o colegio te dio un perfil específico, búscalo en la lista.

🌟 Perfil Flexible: Permite escribir código con reglas más relajadas (ideal para comenzar).

🔒 Perfil Estricto: Exige una sintaxis más rigurosa similar a lenguajes reales como C++ o Java.

Selecciona tu perfil y haz clic en Aceptar 👍.

💻 Cómo Usar PSeInt Paso a Paso
Paso 1: Crear un Nuevo Archivo 📄
Abre PSeInt. Verás una plantilla básica en el editor:

Fragmento de código
Algoritmo SinTitulo
    
FinAlgoritmo
Paso 2: Escribir tu Primer Programa ✍️
Cambia el nombre del algoritmo e ingresa instrucciones. Por ejemplo, un clásico "Hola Mundo":

Fragmento de código
Algoritmo HolaMundo
    Escribir "¡Hola, mundo! Bienvenido a PSeInt 🚀"
FinAlgoritmo
Paso 3: Guardar el Archivo 💾
Ve al menú Archivo ➡️ Guardar como...

Asigna un nombre a tu algoritmo y guárdalo con la extensión .psc.

Paso 4: Ejecutar el Algoritmo ▶️
Haz clic en el botón verde con forma de flecha Ejecutar (o presiona la tecla F9).

Se abrirá la consola mostrando el resultado de tu programa 🖥️.

🛠️ Herramientas Útiles
📊 Diagrama de Flujo: Haz clic en el ícono de diagrama en la barra superior para generar automáticamente el diagrama de tu pseudocódigo.

🐾 Paso a Paso: Utiliza el botón de ejecución paso a paso para ver cómo se ejecuta cada línea en tiempo real y detectar errores.

💡 Panel Lateral: Utiliza los botones de la derecha para insertar estructuras rápidamente (Si-Entonces, Mientras, Para, etc.).
